# Админские команды

Разовая установка на сервере (от root):

```bash
cd ~/bloom_app && bash scripts/install.sh
```

Дальше команды работают из любой папки.

## Выдать PRO

```bash
bloom-pro user@example.com            # на 14 дней
bloom-pro user@example.com 30         # на 30 дней
bloom-pro a@x.ru b@y.ru --days 7      # нескольким сразу
```

Повторный запуск **продлевает** подписку, а не перезаписывает. Выдача
помечается в аналитике как `granted_by_admin` с суммой 0 — в выручку
не попадает.

Если точного совпадения по адресу нет, команда покажет похожих: вход
через Яндекс сохраняет тот email, который вернул Яндекс ID, а он часто
отличается от того, что человек назвал.

## Снять PRO

```bash
bloom-pro-revoke user@example.com
```

## Кто регистрировался

```bash
bloom-users              # за последние 7 дней
bloom-users --days 30
bloom-users --all
```

## Как это устроено

`admin_cli.py` выполняется внутри контейнера `api` (там доступ к БД и
`services/`), но сам файл читается с хоста и передаётся через stdin.
Поэтому после `git pull` пересобирать образ не нужно — работает всегда
та версия, что лежит в репозитории.
